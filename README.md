## 🌟 Overview

**EduNexus ERP** is a modern, high-performance educational resource planning platform engineered to unify students, educators, and campus administrators into a single, cohesive digital ecosystem. Designed with real-time state management, gamified academic pathways, automated parent communication, comprehensive staff payroll, and sensory audio-visual themes, EduNexus delivers an unparalleled institutional experience.

---

## ✨ Interactive Guided Tour (Onboarding for New Visitors)

EduNexus ERP includes a built-in **Interactive Onboarding Walkthrough** designed specifically so that **whenever any new person arrives, they receive an immersive, step-by-step tour explaining how to use all the tools across the system**.

- **Automatic First-Arrival Trigger**: Detects first-time visitors automatically and presents a friendly, multi-step guide with live previews of each portal.
- **Always Accessible "Tour" Button**: A prominent `✨ Tour` launcher is anchored directly in the top header, sidebar dock, and mobile drawer so anyone can replay the tour at any time.
- **Live Portal Synchronisation**: As you step through the tour, EduNexus dynamically adapts the active role and module in the background, allowing you to see the actual tool in real-time.
- **Smart Preferences**: Remembers your tour completion status in `localStorage`, with an option to toggle automatic display.

## 🏛️ The 3 Dedicated Portals & Comprehensive Tool Suite

EduNexus is architected around **3 specialized roles**, each offering tailored tools and distinct workflows:

```
                          ┌───────────────────────────┐
                          │   EduNexus ERP Core Bus   │
                          └─────────────┬─────────────┘
                ┌───────────────────────┼───────────────────────┐
                ▼                       ▼                       ▼
     ┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐
     │   Student Portal    │ │   Teacher Portal    │ │  Management Portal  │
     │  (Learner Pathways) │ │ (Classroom Command) │ │(Executive Governance│
     └─────────────────────┘ └─────────────────────┘ └─────────────────────┘
```

### 1. 🎓 Student Portal (Learner Command & Gamification)

Built to keep students engaged, accountable, and academically empowered:

- **Academic Dashboard & XP Progression**: Live attendance percentage tracker, total accumulated XP points, house points (Agni, Jal, Vayu, Prithvi), and profile views.
- **NCERT Formula Vault & Periodic Table**: Quick-reference formulas across Physics, Chemistry, and Mathematics, plus an interactive chemical elements database.
- **Exam Readiness Hub & Daily Test Engine**: Timed MCQ practice assessments with instantaneous scoring, answer key breakdown, and bonus XP rewards.
- **Tuition & Digital Receipts**: Transparent term fee installments breakdown with one-click simulated UPI/NEFT payments and numbered receipt generation.
- **CBSE Digital Report Card**: Official report card generation featuring term marks, grade points, overall percentage, and a **1-click printable PDF view**.
- **Peer Tutoring Hub**: Community request board where students can seek help in complex STEM topics or volunteer as peer mentors.
- **Study Channels & Chat**: Real-time subject discussion groups and class channels.
- **Confidential Desk & Leave Applications**: Secure submission of leave requests and discreet wellness reporting.

---

### 2. 👨‍🏫 Teacher Portal (Classroom Command & Faculty Tools)

Engineered for zero-friction classroom management and rapid faculty execution:

- **Teacher Command & Schedule**: Period-by-period timetable with real-time class indicators and a 1-click **"Join Period"** action.
- **One-Click Roll Call Attendance**: Fast attendance logging (Present, Absent, Late) across classes (9-A through 12-A) with live attendance percentages.
- **Instant Automated Parent Alerts (SMS & WhatsApp)**: Send automated SMS and WhatsApp alerts to parents with 1 click when an unexcused absence, fee reminder, or notification is triggered.
- **Gradebook & Marks Entry**: Enter marks for Unit Tests, Half Yearly, and Final examinations with automatic percentage and grade computation.
- **Conduct & Disciplinary Log**: Record behavioral commendations or infractions directly to the student's institutional record.
- **Teacher Notices & Homework Dispatch**: Publish assignments, submission deadlines, and syllabus updates directly to student feeds.
- **Class Chat & Channels**: Moderate student channels and post real-time classroom updates.

---

### 3. 🏛️ Management & Administration Portal (Directorate Governance)

Comprehensive administrative command over campus finances, HR, and daily facilities:

- **Executive Directorate Command**: High-level school KPIs, total enrollment, staff-to-student ratios, and operational alerts.
- **Campus Staff HR & Payroll Engine**: Complete directory of teaching faculty, lab technicians, IT support, and sanitation staff. Manage basic pay, allowances, deductions, and disburse bank transfers.
- **Printable Salary Vouchers**: Generate official, numbered salary slips with breakdown of earnings and statutory deductions.
- **Student Fee Dues & Defaulter Audit**: Track pending tuition balances by section and dispatch mass parent fee reminders with one click.
- **Campus Operations & Sanitation**: Monitor live status of campus water purifiers, chemistry labs, computer hardware, solar arrays, and custodial work orders.
- **Conduct Tribunal**: Review and adjudicate student behavioral reports, issue guidance notes, and resolve campus concerns.
- **Official Circulars & School Broadcast**: Publish school-wide circulars with urgent banner broadcasts.

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18.0.0 or higher)
- **npm** (v9.0.0 or higher) or **bun**

### Installation

1. Clone or initialize the repository:
   ```bash
   git clone <repository-url>
   cd edunexus-erp
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. (Optional) Configure environment variables:
   ```bash
   cp .env.example .env.local
   ```
   Add your `GEMINI_API_KEY` if using AI Studio features.

4. Start the local development server:
   ```bash
   npm run dev
   ```
   The application will be running locally at `http://localhost:3000`.

5. Build for production:
   ```bash
   npm run build
   ```

6. Type-check with TypeScript:
   ```bash
   npm run lint
   ```

## ⌨️ Keyboard Shortcuts & Quick Tips

| Key / Action | Description |
|---|---|
| `✨ Tour` in Header / Sidebar | Open the Interactive Guided Tour anytime |
| `→` / `←` inside Tour | Navigate between tour steps |
| `Esc` inside Tour / Modals | Close the modal or tour |
| `Role Switcher` (Top Bar) | Instant toggle between Student, Teacher, and Admin |
| `Section Dropdown` | Jump directly to any module within the current role |
| `Sidebar Dock Toggle` | Collapse sidebar to compact icon rail or expand |
